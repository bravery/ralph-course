常见问题 1：AI 卡住了

AI 可能陷入无限循环或长时间没有进展。

症状
# progress.txt 中看到：
# 同一条消息重复出现
"AI: Installing dependencies..." # 多次出现
"AI: Building project..." # 循环
原因和解决

可能原因：npm/yarn 依赖问题，缓存冲突，网络问题

解决方案 1：清理依赖：rm -rf node_modules && rm package-lock.json && npm install

解决方案 2：检查网络连接，重试

解决方案 3：在 prd.json 中减小任务范围

常见问题 2：Typecheck 失败

AI 修改的代码有类型错误。

progress.txt 中的错误
# Typecheck: FAILED
error TS2322: Type 'string | undefined' is not assignable to type 'string'
# src/components/TaskCard.tsx:45
如何帮助 Ralph

方法 1：AI 通常会自动修复类型错误

方法 2：如果反复失败，可以更详细描述要求

方法 3：检查 AGENTS.md 是否有相关编码规范

方法 4：手动修复并提交，让 Ralph 继续下一个故事

常见问题 3：验收标准未完成

故事标记为完成，但验收标准没有全部满足。

prd.json 状态
"userStories": [
{
"id": "US-003",
"title": "Show priority badge",
"passes": false // 标记为未完成
}
]
为什么发生

原因 1：AI 认为已完成，但实际未通过所有验证

原因 2：验收标准描述不清晰，AI 理解有误

原因 3：测试/Typecheck 通过了，但 UI 没验证

解决方法：检查哪些验收标准未满足，添加更具体的描述

常见问题 4：git 冲突

当多个功能分支同时开发时可能发生冲突。

症状
# AI 提交时遇到错误
"error: merge conflicts"
"src/utils/api.ts contains conflicts"
如何处理

AI 无法自动解决冲突：需要人工介入

步骤 1：查看 conflict markers <<<<<<< HEAD

步骤 2：手动编辑文件，选择保留哪个版本

步骤 3：标记冲突已解决：git add 文件名

步骤 4：完成合并：git commit

预防：使用更小的故事，减少同时修改的文件数量

💡 调试原则

1. 先看日志 - progress.txt 记录所有操作

2. 再查状态 - prd.json 显示任务完成情况

3. 最后动手 - 先分析再修复，避免盲目操作

4. 学会预防 - 好的任务拆分能避免大部分问题

当 AI 完全迷失方向

有时 AI 会做出完全无关的修改。

⚠️ 警告信号

"AI: Added README.md" - 但你要求的是 UI 修改

"AI: Deleted src/ 目录" - 灾难性错误

进度停滞 - 反复修改同一文件，无进展

验收标准全未满足 - AI 完全误解任务

恢复策略
# 方案 1：从 archive 恢复
cp archive/2025-04-13-old-feature/prd.json .
# 方案 2：git 回退
git reset --hard HEAD~1
# 方案 3：重新开始
rm progress.txt # 重置进度
rm prd.json
cp prd.json.template prd.json
预防措施

1. 小故事 - 减少 AI 犯错空间

2. 清晰验收标准 - 避免误解

3. AGENTS.md 模式 - 提供编码规范

4. 定期检查 - 不要完全放手不管
